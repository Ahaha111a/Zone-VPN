# Railway: тестовый запуск Zona VPN

## Назначение
Railway подходит для проверки Telegram-бота, но этот набор настроек не разворачивает Xray и не делает VPN готовым к выдаче пользователям. По умолчанию продажи выключены, а `VPN_MODE=disabled`. Не меняйте их на `true`/`xray` для обхода отсутствующей интеграции.

## Деплой
1. Создайте приватный GitHub-репозиторий и загрузите содержимое проекта в корень репозитория.
2. В Railway создайте Project → Deploy from GitHub Repo и выберите этот репозиторий.
3. В Variables добавьте `BOT_TOKEN` (токен из BotFather), `ADMIN_IDS` (ваш числовой Telegram user ID), `DATABASE_PATH=/data/zona.sqlite3`, `VPN_MODE=disabled`, `SALES_ENABLED=false`, `PAYMENT_DELIVERY_READY=false`, `LOG_LEVEL=INFO`. `SUPPORT_USERNAME` и `TERMS_URL` пока можно не задавать.
4. Создайте Volume в Railway и подключите его к сервису по mount path `/data`. Без volume SQLite-файл может потеряться при новом деплое/пересоздании контейнера.
5. Убедитесь, что сервис работает как один постоянно работающий worker: не создавайте вторую реплику и не запускайте локально этот же токен одновременно, иначе два процесса могут конфликтовать за Telegram long polling.
6. Откройте Deployments → View Logs. Успешный запуск не должен содержать `BOT_TOKEN не задан`, ошибки импорта или повторяющиеся `Conflict: terminated by other getUpdates request`.
7. Откройте бота в Telegram и проверьте `/start`, `/help`, `/plans`, `/subscription`, `/connect`, `/support`, `/terms`, `/admin`. `/admin` разрешён только ID из `ADMIN_IDS`. В `/connect` бот должен честно сообщать, что адаптер не подключён. Выберите тариф: при текущих флагах покупка должна быть заблокирована и не должна списывать Stars.

## Тесты
В локальном окружении из корня проекта: `python -m pip install -r requirements.txt`, затем `python -m pytest -q`. Перед первым деплоем убедитесь, что GitHub Actions workflow проходит.

## Биллинг и безопасность
Railway Trial предоставляет ограниченный разовый кредит на ограниченный срок; Free затем даёт только $1 месячного кредита, а Hobby стоит $5/мес плюс возможное превышение. Проверьте актуальные условия на https://docs.railway.com/pricing/plans и лимиты до запуска. Ничего не апгрейдите и не добавляйте платёжный метод без отдельного решения. Не публикуйте `BOT_TOKEN`, не вставляйте его в GitHub, README или скриншоты.

## Ограничения текущего MVP
- Нет Xray-адаптера и реальной выдачи VPN-конфигураций.
- Продажи выключены по умолчанию.
- Нужны полноценные тесты обработки платежей и возвратов, проверка доставки/отзыва доступа и проверка уведомлений на границах дат.
- SQLite годится только для одного экземпляра бота с постоянным томом; перед масштабированием нужен переход на PostgreSQL.
