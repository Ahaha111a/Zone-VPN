# Zona VPN — решение по инфраструктуре (исследование на 2026-10-25)

## Решение сейчас

**Не создавать и не оплачивать сервер до юридической проверки модели работы и продавца.** Разработка ведётся локально/в GitHub; продакшен-секреты не помещать в репозиторий.

Для MVP предполагается один Linux VPS, на котором работают Telegram-бот и Xray, с отдельным постоянным хранилищем данных и проверяемыми резервными копиями. Это экономит деньги, но не обеспечивает отказоустойчивость: при падении сервера одновременно недоступны бот и VPN. SQLite допустим только для одиночного сервера и умеренной нагрузки; до появления нескольких экземпляров нужен PostgreSQL.

## Требования к серверу перед заказом

- Linux LTS, минимум 2 GB RAM для начального совмещённого бота и Xray; окончательный размер зависит от теста нагрузки.
- Публичный IPv4, возможность открыть нужные TCP-порты и политика провайдера, прямо допускающая VPN-сервисы.
- Проверяемая цена продления без промо, стоимость IPv4, трафика, снимков и резервных копий.
- SSH-ключи вместо парольного входа; firewall с закрытыми по умолчанию портами; обновления безопасности.
- Бэкап базы и конфигурации вне основного сервера, проверка восстановления.
- Мониторинг свободного места, доступности бота, Xray, срока сертификатов/ключей и ошибок выдачи/отзыва клиентов.
- Запрет логирования содержимого трафика и истории посещений. Хранить только минимальные данные, необходимые для работы подписки и поддержки.
